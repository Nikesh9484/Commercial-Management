Fonts used to write values onto the RSG forms in Document Packs, matching the faces the approved forms are set in.

- Noto Sans (Regular, Bold, Italic, Bold Italic) – SIL Open Font License 1.1 – https://github.com/googlefonts/noto-fonts
- Open Sans (Regular, Bold, Italic) – SIL Open Font License 1.1 – https://github.com/googlefonts/opensans
- Liberation Sans (Regular, Bold, Italic, Bold Italic) – SIL Open Font License 1.1 – metric-compatible with Arial
